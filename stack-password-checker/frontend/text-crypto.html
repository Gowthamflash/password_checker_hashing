Text encryption and decryption

At least 8 characters. A long passphrase is best. You can test one in the Password Checker.

Keep your password safe. It is not stored anywhere. If you lose it, the encrypted message may be unrecoverable by you, by us, or by anyone else.

Your message, password and keys never leave this page. Encryption and decryption run in your browser using the Web Crypto API. Nothing is sent to the server or saved in the browser, and everything is cleared when you press Clear or leave the page.

How it works

  • AES-256-GCM encrypts the message and also detects any change to it. A wrong password or a modified message is rejected instead of producing garbage.
  • PBKDF2-SHA-256, 600,000 iterations turns your password into the 256-bit key. This makes each password guess slow for an attacker. Your password is never used as the key directly.
  • New random salt and IV every time. Encrypting the same message twice gives different output. The key is not hard-coded anywhere.
  • Versioned envelope. The output is a Base64 text that holds the format version, algorithms, iteration count, salt, IV and ciphertext. The iteration count and salt are authenticated, so changing them breaks decryption.
  • Limits. Encryption hides the content of the message, not the fact that a message exists or its approximate length.
