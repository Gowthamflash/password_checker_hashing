How it works

  • AES-256-GCM with a key from PBKDF2-SHA-256 (600,000 iterations). A fresh random salt and IV are created for every encryption, so the same file never encrypts the same way twice.
  • Tamper detection. The header, file name, type, size and contents are all authenticated. A wrong password or a modified file is rejected.
  • The original file name and type are preserved inside the encrypted data, so they are not visible in the encrypted file.
  • Size limit. The whole file is processed in memory at once, which needs several times the file size in RAM. That is why the limit is 64 MB and not unlimited.
