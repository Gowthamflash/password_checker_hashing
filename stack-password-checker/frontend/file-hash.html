File Hashing

local only
Drag and drop files here Images, text, PDF, DOCX and any other file. Up to 2 GB each.

    Hashing checks integrity. It does not encrypt or hide your file. The same bytes always give the same hash, and a changed file gives a different one. A hash is not proof that a file is safe.

    Files are read and hashed in your browser, exactly as stored on your device. They are not uploaded to the server, and nothing is saved. Uploaded files are never opened or run; image previews are shown only for common image types.
